# 数据源

**核心结论**：新股申购/上市信息没有稳定可靠的公开 API（东财 push2 的打新相关接口不稳定/需认证），**以网页搜索为主力路径**，执行 Workflow 时用以下搜索模板，取东方财富/新浪财经/同花顺等权威财经媒体的页面，注明来源与页面标注日期。

## 搜索模板（网页搜索主力）

- 本周申购：`本周新股申购一览`（首选；覆盖周一到周日）
- 当日申购：`今日新股申购`（用于当日提醒/确认单只新股细节）
- 本周上市：`本周新股上市`（确认上市时间表）
- 中签公布：`本周新股中签结果` / `新股中签结果 缴款`（对本周公布中签结果的新股，用于中签缴款提醒）
- 上市首日表现：`新股上市首日涨幅` + 新股名称（可选；以收盘价为准）
- 发行价/市盈率细节：`新股发行价 市盈率 申购上限` + 新股名称（可选；用于补齐 Output Contract 的字段）

## 媒体来源优先级

东方财富网（data.eastmoney.com 数据中心新股栏目、资讯频道）＞ 新浪财经 ＞ 同花顺 ＞ 证券时报网/e公司 ＞ 其他门户财经频道。

**引用时必须注明**：来源名称 + 来源页面标注的日期（如"东方财富，9-27 发布"）。不同媒体口径矛盾时以发行公司公告/官方信息为准；无法确定时标注"待确认"。

## 备选：东财数据中心

`https://data.eastmoney.com/` 相关新股栏目——页面 JS 重度渲染，普通 HTTP 抓取拿不到数据，**仅在有浏览器自动化环境时作为备选**，否则直接用网页搜索。

## 已知实例（2026-09-29 实测写入，供交叉核对）

- 9-28 已申购：联亚药业 301569、南方乳业 920196
- 本周上市：鸿富诚 301716、安达股份 920202

## 兜底规则

搜索无结果、页面下线或数据矛盾时，一律在输出中明确说明情况（如"本周无新股申购（网页搜索 9-29，未见新股公告）"），标注"待确认"的缺项，**不编造**。
